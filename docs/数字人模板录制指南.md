# 数字人模板视频 · 录制指南与台词

录好后把视频文件直接放进这个文件夹（/Volumes/Storage/avatar-template/），告诉我文件名即可。

## 核心认知（为什么这么录）

这段视频的**音频最终会被丢掉**，AI 只用画面：每期视频用你的克隆声音出音频，引擎把这段视频里你的嘴型改成对上新音频。所以：
- 不用背稿，不用念得一字不差，忘词就自由发挥接着聊——**状态比内容重要**；
- 你的表情、头动、眨眼会原样保留在成片里，所以要"跟朋友聊天"的放松状态，别有"念稿感"。

## 录制清单

| 项目 | 要求 |
|---|---|
| 构图 | **手机竖屏 9:16，胸部以上半身**，脸在画面上半部，头顶留一点空间 |
| 画质 | 能开 4K 就开 4K（将来全屏出镜直接复用这条素材），最低 1080p；30fps 即可 |
| 固定 | 三脚架或把手机稳稳靠住——全程机位不动 |
| 光线 | 正面或前侧光（面对窗户/台灯），脸部亮而均匀；**别背对窗户逆光** |
| 背景 | 干净、没动静就行，**不需要白墙**（见下方"背景三忌"） |
| 眼神 | 看**摄像头小黑点**，别看屏幕里的自己；偶尔自然瞟开一下反而真实 |
| 头动 | 自然小幅度即可；别大幅转头、低头看稿 |
| 手 | 可以有自然的聊天手势，但**别抬到脸附近**、别挡嘴 |
| **嘴型（2026-08-09 实测新规，最重要的一条）** | **首选：全程闭嘴的"聆听状态"**——嘴唇自然轻闭、微笑、点头、眨眼都可以，但**不说话、不张嘴**。实测发现：配音静默的间隙里，AI 会部分"还原"模板当时的嘴型——模板张着嘴，成片静默时嘴就会微张露齿；模板闭着嘴，静默时就自然闭合。说话段不受影响（新音频会正常驱动开口）。 |
| 语速（旧式说话模板，仍可用但静默段嘴型略差） | 正常聊天速度，**句子之间自然闭嘴停顿**——这些闭嘴间隙对效果很重要 |
| 开头结尾 | 各留 **5 秒不说话**：看镜头、自然微笑或轻微点头（用来做循环接缝和安静段） |
| 时长 | 正片 2–3 分钟（下面的台词读完大约就是这个长度） |

## 背景三忌（比"白不白墙"重要得多）

1. **背后不能有别人、带人脸的海报/照片/电视画面**——人脸检测可能认错脸；
2. **不能有镜子或强反光**——会出现第二个你；
3. **没有会动的东西**（宠物、风吹的窗帘、屏幕动画）。

白墙可以但不是必须；浅灰、米色墙面或整洁的书架都行。建议选**纯色干净背景**：这条素材将来全屏出镜、抠像换背景都能复用，一次录制终身受益。

## 台词（约 2 分钟；照读、改词、自由发挥都可以）

> 大家好啊，好久没有这样坐下来，跟大家面对面聊聊天了。平时都是我在配音，今天算是正式跟大家打个照面。
>
> 我为什么喜欢网球呢？其实一开始，就是觉得这项运动特别干净。一个人站在场上，没有队友可以依靠，赢了是你的，输了也是你的。所有的情绪，都得自己消化。这一点，跟我们普通人的生活，其实挺像的。
>
> 我做这些视频，就是想把那些打动我的瞬间，讲给你们听。有的球员，十几年就赢了那么一次；有的人，职业生涯一直在受伤、复出、再受伤。你看比分只是几个数字，但背后都是一个一个活生生的人。
>
> 有时候我剪素材，看到一个镜头，会停下来看好几遍。那种感觉很难形容，就是你知道，这个瞬间对他来说意味着什么。
>
> 对了，你们平时看比赛，是喜欢看直播呢，还是喜欢看集锦？我自己是两种都看。直播有悬念，集锦有情绪，各有各的好。
>
> 以后这个小头像呢，会经常出现在视频的角落里，陪大家一起看这些故事。你们要是有想听的球员、想听的比赛，就在评论区告诉我。
>
> 好，那今天就先聊到这儿。我们视频里见。

### 加长段（想凑到 3 分钟就接着读这段）

> 再多说一句。很多人问我，这些视频是怎么做出来的。其实每一期，从查资料、写稿子、找素材，到最后剪出来，都要花不少时间。最难的部分，是确认每一个镜头里的人，就是我说的那个人。观众可能不会注意到，但我知道，你们值得看到准确的东西。所以每一期视频，我都会尽量做到，讲的每一句话都有出处，用的每一个镜头都对得上人。
